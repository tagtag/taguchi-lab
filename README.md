# Taguchi Laboratory / 田口研究室

A bilingual, static website for Taguchi Laboratory (Nonlinear Physics Laboratory), Chuo University. The Japanese home page is `index.html`; the English version is `en/index.html`. It needs no build step or server-side code.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `taguchi-lab`.
2. Upload **the contents of this folder** to the repository root, preserving the `en` folder.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/ (root)`. Save.
4. GitHub Pages will provide a URL such as `https://YOUR-USERNAME.github.io/taguchi-lab/`. The English page is at `/en/`.

Relative links work under both a project URL and a custom domain. No account, analytics, form, or build service is required.

## Before publishing

- Review the Japanese and English text, especially the research description and laboratory name.
- Add a preferred institutional contact route if desired. The page currently points to the official faculty profile and university listing.
- The `YT` monogram is a design element, not a portrait or university logo.

Research affiliations and topics were checked against Chuo University's faculty listing and researcher profiles in September 2026. Publication links are DOI links.
